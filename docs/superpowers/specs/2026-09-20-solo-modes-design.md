# 솔로 플레이 모드 설계 (봇과 대결 / 깃발 찾기 / 자유 연습)

승인일: 2026-09-20 · 상태: 승인됨(구현 전)

## 1. 목표와 범위

혼자서도 즐길 수 있는 모드 3가지를 추가한다. 4인 멀티(M0~M5)의 흐름과 규칙은 바꾸지 않는다.

| 모드 | 요약 |
|---|---|
| 봇과 대결 | AI 봇 1~3명과 깃발 뽑기 대결. 봇을 모두 탈락시키면 승리, 내 깃발이 뽑히면 패배 |
| 깃발 찾기 타임어택 | 주인 없는 금색 깃발을 모두 뽑는 시간을 잰다. 크기별 최고 기록을 내 PC에 저장 |
| 자유 연습 | 깃발도 승패도 없는 탐험 모드 |

**이번 범위에서 제외:** 봇의 아이템 사용(M6에서 결정, 지금 봇은 아이템 없이 동작), 멀티 방의 빈 자리를 봇으로 채우기(나중에 붙일 수 있게만 설계).

## 2. 화면 흐름

- 타이틀: `[방 만들기] [참가하기] [혼자 하기]`.
- 혼자 하기 → **모드 카드 3장** → 테마 카드(기존) → 크기(기존, 확정 버튼 문구 "시작") → *(봇과 대결일 때만)* **봇 수(1~3, 기본 3) + 난이도(쉬움/보통/어려움, 기본 보통)** → 바로 시작.
- 각 화면의 "뒤로"는 한 단계 전 화면으로 돌아간다(솔로 흐름에서 테마 화면의 뒤로는 모드 카드).
- 대기실은 거치지 않는다.

## 3. 솔로 방 (네트워크)

- 솔로도 지금 구조(NetworkManager 호스트)를 그대로 쓰되 **내 PC 안에서만** 연다: 수신 주소 `127.0.0.1`, LAN 방 검색 알림 없음, 다른 접속은 "혼자 하기 방이에요."로 거절. 방화벽 창이 뜨지 않는다.
- 기본 포트 7777이 이미 쓰이고 있으면 7778~7786 중 빈 포트를 쓴다.
- `NetworkSession`에 `IsSolo`, `Mode`, `BotCount`, `BotDifficulty`(NetworkVariable)를 추가한다. `ConfigureSolo(mode, botCount, difficulty)`와 `StartSoloGame()`(준비/최소 인원 검사 없이 즉시 시작)을 서버가 호출한다.
- **재시작**: `RestartSolo()`는 게임 오브젝트를 정리하고(멀티의 `ReturnToLobby`와 같은 정리 코드 공유) 같은 설정으로 새 seed의 게임을 바로 시작한다.
- Game 씬을 직접 실행하는 개발용 경로는 **자유 연습**의 솔로 방으로 동작한다.

## 4. 플레이어 식별자 (`PlayerId`)

- 지금은 깃발/탈락 기록/관전이 접속 번호(`OwnerClientId`)로 플레이어를 가리킨다. 봇은 접속이 없으므로 `NetworkPlayer.PlayerId`를 새로 둔다.
  - 사람: `OwnerClientId`와 같음. 봇: `1000 + n`. 금색 깃발: `2000 + n`(주인 없는 깃발).
  - 스폰 페이로드(`OnSynchronize`)로 `PlayerId`와 `IsBot`을 전달한다.
- `NetworkPlayer.Find(id)`, `Flag.PlayerId`, `MatchEntry.clientId`, 깃발 뽑기 요청, `FlagPuller`/`SpectatorView`/HUD의 조회는 모두 `PlayerId` 기준으로 한다. 사람은 두 값이 같아서 멀티 동작은 그대로다.
- `IsOwner`를 "로컬 사람"의 뜻으로 쓰는 곳(시선 동기화, 관전 진입, 로컬 세팅)은 봇(서버 소유)이 걸리지 않게 `IsBot`을 제외한다.

## 5. 게임 모드와 승패 규칙 (`MatchManager`)

`GameMode { Versus, Bots, Treasure, Practice }`를 세션에서 읽어 `MatchManager`가 복제한다.

- **Versus**: 기존 그대로.
- **Bots**: 사람 1 + 봇 N이 모두 깃발을 가진다. 한 명만 남으면 종료(사람이 남으면 승리). **사람이 탈락하면 즉시 종료(패배)** — 남은 봇끼리 계속 싸우지 않는다.
- **Treasure**: 사람의 깃발은 없다. 금색 깃발 `size/10`개(50→5 … 200→20)를 **서로 떨어진 무작위 칸**에 세운다(결정적 배치, 시작 칸에서도 떨어짐). 깃발을 뽑으면 `Collected`가 오르고 모두 뽑으면 종료. HUD "깃발 3 / 10 · 02:31".
- **Practice**: 깃발/승패 없음. HUD "자유 연습 · 경과 시간". 종료되지 않는다.
- 기록: `PlayerPrefs`의 `mirro.treasure.best.<크기>`에 초 단위 최고 기록을 저장하고, 결과 화면이 이전 기록과 비교해 "새 기록!"을 표시한다.

## 6. 봇

봇은 **플레이어 프리팹 그대로** 쓰고, 서버(방장 PC)의 `BotBrain`이 조종한다. 서버가 소유한 오브젝트라 이동은 서버 권위이고, 몸체/색/탈락 표시/관전 대상은 기존 것을 재사용한다. 봇은 로비 슬롯이 없고, 색은 사람이 쓰지 않는 색을 순서대로 받는다.

| | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 방식 | 탐색형 | 추격형 | 추격형 |
| 이동 속도 | 3 m/s | 4 m/s | 5 m/s |
| 출발 지연(경기 시작 후) | 45초 | 25초 | 10초 |

- **추격형**: 미로를 알고, 자기 칸에서 BFS로 **가장 가까운 남의 깃발**까지의 최단 경로를 구해 따라간다. 목표 깃발이 사라지면(주인이 탈락) 다시 고른다.
- **탐색형**: 가본 칸을 기억하고 **가장 가까운 안 가본 칸**으로 이동한다. 0.5초마다 경로 12칸 안에 남의 깃발이 있는지 확인해 있으면 추격으로 전환하고, 목표가 사라지면 탐색으로 돌아간다.
- **깃발 뽑기**: 깃발 칸 안에서 사람과 같은 `PullSeconds`(1.5초) 동안 제자리에 선 뒤 서버 검증(`ServerTryPullFlag`)을 통과해야 한다.
- **이동**: 경로의 칸 중심을 차례로 향해 `CharacterController`로 걷고, 진행 방향으로 몸을 돌린다. 봇끼리는 물리 충돌을 무시한다(복도 정면충돌 교착 방지). 사람과는 충돌하며, 1.5초 동안 0.4m도 못 나아가면 옆으로 비켜서 다시 길을 찾는다.
- 경로 탐색은 `BotPathfinder.FindPath(maze, 출발 칸, 목표 조건, 최대 깊이)` 한 가지로 통일한다(BFS + 부모 배열).

## 7. UI/메뉴 변경

- **결과 화면**: 순위 표에 봇은 "(봇)"으로 표시한다. 사람이 탈락해 끝나면 제목 "패배", 남은 생존자는 "생존"으로 맨 위에 둔다. 깃발 찾기는 "완료!" + 기록/최고 기록. 솔로의 "다시 하기"는 `RestartSolo()`.
- **일시정지 메뉴(솔로)**: 계속하기 / **다시 시작**(두 번 눌러 확인) / 메인 메뉴.
- **HUD**: 모드별 상단 표시(생존 n / m, 깃발 n / m · 시간, 자유 연습 · 시간).
- **새 UI**: `SoloModeScreen`(모드 카드), `BotOptionsScreen`(봇 수/난이도). 나머지는 기존 화면 재사용.

## 8. 테스트

실제 메뉴 클릭으로 진행하는 자동 플레이테스트 역할 3개(`solobots`, `solohunt`, `solopractice`)와 셀프 테스트를 추가한다. 기존 멀티(4/3/2인)와 솔로 회귀 테스트는 그대로 통과해야 한다.

- 셀프 테스트(`MazeSelfTest`): `BotPathfinder`(경로가 인접 칸으로 이어지고 최단 길이와 같음, 최대 깊이 준수), 탐색형이 미로 전체를 훑고 멀리 둔 깃발을 찾음, 금색 깃발 배치(개수/중복 없음/최소 간격/시작 칸에서 떨어짐/결정적).
- **봇과 대결**: 봇 수/색/깃발/HUD, 출발 지연 전에는 정지 후 이동 시작, 벽 침범 없음, 목표를 향해 경로 거리가 줄어듦, 봇을 내 깃발 옆으로 옮기면 뽑아서 패배 결과 화면(봇 표시)이 뜸, "다시 하기"로 새 seed 재시작, 내가 봇 깃발을 모두 뽑으면 승리.
- **깃발 찾기**: 개수/금색/HUD 카운터·시간, 깃발을 뽑을 때마다 카운터 증가, 모두 뽑으면 결과와 기록 저장·갱신, 재시작 시 카운터 초기화.
- **자유 연습**: 깃발 없음, 끝나지 않음, 일시정지 메뉴의 다시 시작(새 seed)/메인 메뉴.
- **솔로 방**: 다른 접속(늦은 접속 역할)이 "혼자 하기 방이에요."로 거절되고 방 검색 목록에 뜨지 않음.
- 테스트 전용으로 봇 출발 지연/속도를 덮어쓰는 정적 값(`BotBrain.StartDelayOverride` 등)을 둔다.

## 9. 위험과 대응

- 큰 미로에서 쉬움(탐색형) 봇은 사람을 오래 못 찾을 수 있다 → 의도한 "쉬움"이며, 사람은 언제든 봇 깃발을 뽑아 이길 수 있다.
- 식별자 정리(`PlayerId`)가 멀티 동작을 깨뜨릴 수 있다 → 가장 먼저 하고, 기존 멀티 자동 테스트로 회귀를 확인한 뒤 다음 단계로 간다.
